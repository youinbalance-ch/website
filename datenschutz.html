Hosting und technische Zugriffsdaten

Diese Website wird über GitHub Pages bereitgestellt, einen Hostingdienst von GitHub. Beim Aufruf werden technische Verbindungsdaten verarbeitet, damit dein Browser die Seiten laden kann. Dazu gehören insbesondere deine IP-Adresse, Zeitpunkt und angeforderte Adresse sowie vom Browser übermittelte Angaben, etwa zum Browser oder zur verweisenden Seite.

GitHub protokolliert und speichert die IP-Adressen von Besuchenden nach eigenen Angaben zu Sicherheitszwecken, auch ohne GitHub-Anmeldung. Weitere Informationen findest du in der Dokumentation zu GitHub Pages und in der Datenschutzerklärung von GitHub.

Kontaktformular und E-Mail

Das Formular übermittelt deine Eingaben nicht an einen Formularserver. Informationen zu Datenstandorten, Empfängern und Schutzmassnahmen findest du in der Datenschutzerklärung von Google.
