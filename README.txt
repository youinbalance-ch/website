UPLOAD
ZIP entpacken. Den gesamten Inhalt dieses Ordners in Tatjanavivg/website
hochladen, sodass index.html direkt im Hauptverzeichnis des Repositorys liegt.
Den Ordner assets vollständig mit hochladen; die Ordnerstruktur beibehalten.
quellcode/build.py ist die bearbeitbare Quelle der zwölf HTML-Seiten.
README.txt und quellcode dürfen ebenfalls ins Repository; sie müssen nicht
ins spätere öffentliche Hosting-Verzeichnis übernommen werden.

BEARBEITUNG
Texte werden in quellcode/build.py gepflegt. Mit Python 3 ausführen:
python quellcode/build.py
Danach die erzeugten HTML-Dateien zusammen mit der Quelle aktualisieren.
CSS und JavaScript liegen unter assets und werden direkt dort bearbeitet.
